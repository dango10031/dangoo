## 本轮续做

- 本轮验收以用户确认的线上节点生成可用为前提，集中验证 Agent 调用、授权、恢复与 UI 状态。线上登录、钱包和模型目录接口已通过只读联调；线上 Agent 桥接返回 404，功能仍为待部署候选。
- 补充 VibeX `X-Pb-Auth` 桥接认证选项；HTTP 模式支持同账号多个画布，会话建立前校验业务画布权限。离开画布后，尚在等待宿主保存的发送请求终止。
- 扣费确认精确绑定运行和报价，增加自然语言授权来源、免费执行、拒绝、失效及重复调用回归；完整 72 项测试通过。

- 每个用户的每个画布绑定唯一持久会话，进入画布自动恢复；并发初始化复用同一会话，旧重复会话历史保留。
- 自动压缩阈值为 256,000 tokens，计算包含系统提示、工具定义、消息、图片及输出预留；较小 Provider 窗口提前触发。当前默认窗口配置为 128,000，尚未验证 GLM 账户实际支持 256K，不能将压缩阈值当作模型容量声明。压缩保存原始历史并保留完整工具配对、近期消息和固定信息。

- 设置面板只支持平台模型选择。服务端私有持久化并热更新下一轮配置，已有运行保留快照；外部 API 地址、密钥和连接测试配置已删除。
- 图片节点生成已接入业务桥接：连线输入、钱包报价、用户确认或自然语言预授权、幂等提交、任务轮询、永久存储和原节点追加结果。
- 仅扣费时确认，普通节点操作自动执行；预授权按当前对话用户表达由 Agent 理解，无固定额度或有效期。不同画布会话与授权隔离。
- 原生 PocketBase 的端到端 fixture 验证通过；真实出图、原业务登录与钱包扣费流水仍未验证。已实现服务端后台查询，未实现远端取消。

## 历史：外部 GLM 链路（已下线）

以下记录仅用于历史联调背景。当前实现不再读取外部 GLM/兼容 Provider 配置，设置面板也不提供密钥或地址输入。

`npm run check:provider` 实际访问 `https://open.bigmodel.cn/api/paas/v4`，模型 `glm-5.3-flash` 返回 `canvas_probe` 工具调用；此测试使用 179 input tokens、43 output tokens。

通过浏览器对话框发送“创建暖光静物提示词节点”，实际发生 `canvas_read → canvas_apply → canvas_read`。运行完成后 SQLite 画布为 revision 1，节点 `prompt-nuanguang-jingwu` 保存了用户指定的标题和提示词。该会话 ID 为 `fc8bafbe-3198-4160-a816-cf0bc4b69fd1`，持久事件 145 条。

联调发现初版工具 schema 过于宽松导致模型猜测参数；已将所有画布操作改为完整 `oneOf` schema，并补充参数拒绝测试。首次失败尝试已明确停止，没有写入画布。
